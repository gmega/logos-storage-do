Run a Logos Storage node on your machine and try direct and Mix transfers on the private devnet.

Install on Linux x86-64

Run this command as your regular user. You’ll need Bash, curl, jq, tar, gzip, flock, and GNU coreutils.

curl -fsSL https://logos-storage-network.fra1.digitaloceanspaces.com/v0.4/install-linux-x86_64.sh | bash
View installer

Install on macOS · Apple Silicon

Requires macOS 14 or newer and jq. If jq is missing, install it with brew install jq.

curl -fsSL https://logos-storage-network.fra1.digitaloceanspaces.com/v0.4/install-macos-arm64.sh | bash
View installer

Start your node

Run the launch command printed by the installer, then press s in the terminal UI. Your node uses the private devnet bootstrap records and listens on port 8090 by default.

Watch discovery and connections in the status panel. Select a test file with Tab, then press d for a direct download or m for Mix.

Storage module config

Save this as config.json and pass it to the storage module’s init call before calling start. It uses this devnet’s bootstrap nodes, enables Mix, and listens on port 8090.
